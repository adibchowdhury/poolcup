# PoolCup Badge Generation Prompts

## Global Style (Use for EVERY badge)

-   Low-poly 3D game achievement badge matching the existing PoolCup
    badge style.
-   Same shield shape, framing, lighting, proportions and composition as
    the Welcome badge.
-   Exactly the same canvas size and dimensions as the Welcome badge.
-   Transparent background (PNG).
-   Keep the artwork simple: one main subject and at most one supporting
    prop.
-   Minimal floating geometric confetti only.
-   Bold ribbon at the bottom with the badge title in white.
-   PoolCup green color palette. Gold borders may be used for
    higher-tier badges if desired.
-   Crisp, premium game UI quality.
